Comprobar una credencial de Orden Global

Alguien le enseñó una credencial y quiere saber si es de verdad. Péguela aquí. La comprobación ocurre en su navegador: la credencial no se manda a ningún sitio, ni a nosotros.

Comprobarla sin esta página

Esta página es nuestra, así que no debería ser la última palabra. La credencial se firma como firman las billeteras —personal_sign, EIP-191— así que la comprueba cualquier herramienta que ya tenga, sin código nuestro:

import { verifyMessage } from 'ethers'

const { mensaje, firma } = credencial
const quienFirmo = verifyMessage(mensaje, firma)

// Y esta dirección tiene que ser la que Genesis ID publicó EN LA CADENA 5550,
// no la que diga su API. Se lee de la transacción del emisor:
//   eth_getTransactionByHash(<tx del emisor>) → campo "input" → de hex a texto
//   GENESIS-ID/EMISOR/1 <fecha> alg=secp256k1-keccak-eip191 dir=0x…

const vale = quienFirmo.toLowerCase() === direccionLeidaDeLaCadena
  && new Date(JSON.parse(mensaje).expiraEn) > new Date()
  && !revocadasLeidasDeLaCadena.includes(JSON.parse(mensaje).gid)
Cargando de dónde leer la dirección del emisor…

Qué prueba una credencial y qué no. Prueba que Genesis ID verificó a esa persona y qué atributos le consta, en la fecha que dice. No prueba que quien se la está enseñando sea esa persona: eso lo tiene que resolver usted, igual que con cualquier documento.

La ventana de la revocación. Entre que Genesis ID suspende a alguien y que la lista de revocadas se escribe en la cadena pasan horas. Una credencial dentro de esa ventana se ve buena. Es una limitación real y por eso está escrita aquí y no en una nota al pie.
