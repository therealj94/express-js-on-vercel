Te toca a vos

Tres llaves y está en línea

Nada de esto es programación: son cuentas que solo vos podés abrir. En este orden.

01

Base de datos — 10 minutos, gratis para empezar

Abrí una base en Neon o Supabase, copiá la cadena de conexión y ponela como DATABASE_URL en Vercel. Sin esto, todo lo que edites en el admin desaparece cuando el servidor se recicla. Es el único bloqueador real para cobrar de verdad.

02

Stripe — con la entidad de EE. UU.

Creá la cuenta bajo la LLC gringa (Stripe no opera con empresas hondureñas). Poné STRIPE_SECRET_KEY, y agregá un webhook a /api/webhooks/stripe escuchando checkout.session.completed con su STRIPE_WEBHOOK_SECRET. Sin el webhook los pagos entran pero las reservas no se marcan pagadas solas.

03

Correo — Resend con dominio verificado

Verificá el dominio desde el que querés escribir, poné RESEND_API_KEY y MAIL_FROM. Antes de eso, leé los mensajes en el log del servidor: están escritos y probados, pero la redacción es mía y el negocio es tuyo.

04

Y cambiá la contraseña del admin

ADMIN_PASSWORD viene como lovecloud. Cambiala antes de que el sitio sea alcanzable por alguien más.

Cómo probarlo hoy

Corre sin configurar nada

cd roatan-yacht
npm install
npm start → http://localhost:3000

El admin está en /admin.html con la contraseña lovecloud. Sin llaves, la app corre en modo cotización con una base de datos en archivo: podés reservar, editar el catálogo, emitir invoices y ver los correos en la consola. npm run reset devuelve todo al catálogo original.

Probado en navegador real: flujo completo del huésped, arrastre al plano, calendario, cantidades, checkout, confirmación, móvil y admin. Cero errores de JavaScript. Nada desplegado todavía — la decisión de publicar es tuya.
